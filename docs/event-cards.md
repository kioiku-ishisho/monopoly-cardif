# 現實人生｜事件牌清單

Oct 21, 2026 · @kio

本清單共 900 張事件牌：青年、中年、老年三篇，每篇依六類主要影響各 50 張。每張牌寫明事件經過、數值影響，以及屬於「命運」或「機會」。

## 使用說明

| 牌種 | 玩家能否選擇 | 說明 |
| --- | --- | --- |
| 命運 | 不可選擇，抽到即發生 | 生病、意外、裁員、天災等身不由己的事 |
| 機會 | 可選擇「接受」或「放棄」 | 進修、旅遊、投資、換工作等自己決定的事；放棄則無任何影響 |

| 代號 | 影響 | 數值寫法 |
| --- | --- | --- |
| ① | 減少現金 | 現金 −金額（一次性） |
| ② | 增加現金 | 現金 +金額（一次性） |
| ③ | 減少淨收入 | 淨收入 −金額/月（之後每圈持續） |
| ④ | 增加淨收入 | 淨收入 +金額/月（之後每圈持續） |
| ⑤ | 減少健康 | 健康 −點數（健康指數 0–100） |
| ⑥ | 增加健康 | 健康 +點數 |
| ⑦ | 幸福增減 | 幸福 ±點數（幸福指數 0–100，約等於心理健康；歸零遊戲結束） |

- 每張牌依「主要影響」歸類，「影響」欄會列出所有連帶效果，例如進修：現金 −30,000、淨收入 +3,000/月。
- 數值以遊戲現有設定為基準：職業月薪約 38,000–58,000、健康上限 100。中年收入已 ×1.3，老年改領月薪 40% 退休金，數值可依平衡測試再調整。
- 淨收入 = 每圈收入 − 生活開銷，可由加薪、兼職、房租收入提高，也可由降職、貸款、扶養費等降低。
