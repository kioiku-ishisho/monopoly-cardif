# 幸福指數對照表

由 `scripts/happiness-cards.mjs` 產生。共 242 張牌的「健康」影響改為「幸福」：情緒、人際、休閒娛樂、壓力、悲傷與喜悅類的事件。運動、飲食、疾病、受傷、醫療與體力勞累類維持健康。

確認後執行 `npm run import-cards` 上傳到 Firestore；要調整時改腳本裡的 MOVE 清單（或直接改 `docs/event-cards.md`）。
